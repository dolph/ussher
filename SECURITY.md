# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately:

1. Open a [GitHub Security Advisory](https://github.com/dolph/ussher/security/advisories/new) (preferred), or contact the maintainer via their GitHub profile.
2. Include reproduction steps, affected versions, and impact.
3. Do not file public issues for exploitable vulnerabilities.

We aim to acknowledge reports promptly and coordinate disclosure after a fix is available.

## Supported Versions

Security fixes are applied on the default branch and included in the next tagged release.
